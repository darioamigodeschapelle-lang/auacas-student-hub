# AUACAS Student Hub — Alpha

A privacy-first, read-only alpha website for AUACAS students.

## Publish with GitHub Pages

1. Create a new GitHub repository named `auacas-student-hub`.
2. Upload **the contents of this folder** to the repository root. `index.html` must be at the top level.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. GitHub will provide a public address similar to `https://USERNAME.github.io/auacas-student-hub/`.

## Security settings

- Enable two-factor authentication on the repository owner's account.
- Do not add collaborators unless they must edit the official site.
- Protect the `main` branch before adding collaborators.
- Never share passwords, recovery codes, or access tokens.

## Alpha privacy model

- Static and read-only
- No analytics or advertising trackers
- No tracking cookies
- No accounts
- No submissions or uploads
- No collected student information

The hosting provider may retain limited technical security logs under its own policies.

## Updating

Replace `index.html` with an approved new version. GitHub Pages will publish it at the same address.
