# Security

Only the repository owner should have write access during the alpha release.

Recommended controls:

- Enable two-factor authentication.
- Use a strong, unique password.
- Keep the `main` branch protected.
- Do not expose access tokens or recovery codes.
- Review every change before publishing.
- Remove access immediately when it is no longer required.

Visitors can copy public files, but they cannot modify the official published website without repository write access.
